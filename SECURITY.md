# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

The Stellar Threads team takes security seriously. If you discover a vulnerability or potential exploit affecting the wallet integration, transaction verification, or protocol contracts, please report it responsibly.

### How to Report

1. **Do not** report security vulnerabilities via public GitHub issues.
2. Email security inquiries to `security@stellar-threads.org` or open a confidential security advisory through GitHub's Security tab on the repository.
3. Include the following details:
   - A clear description of the vulnerability and its potential impact.
   - Exact steps or proof-of-concept to reproduce the behavior.
   - Any proposed mitigations or code patches.

### Response Timeline

- **Initial Acknowledgement**: Within 48 hours.
- **Triage & Assessment**: Within 5 business days.
- **Resolution & Disclosure**: We follow coordinated disclosure guidelines and will credit responsible researchers.
