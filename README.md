## 🎨 Overview
The **Stellar Threads Frontend Portal** is a production-grade, editorial luxury web application built with **Next.js**, **React 19**, and **Tailwind CSS**. It connects directly to Stellar Testnet smart contracts through **Freighter** and the **Stellar Wallets Kit**.

---

## 💻 Key Features
1. **Multi-Wallet Support**: One-click connection with Freighter, Lobstr, and xBull.
2. **Instant Friendbot Faucet**: Top up testnet accounts with 10,000 XLM directly from the UI.
3. **4-Stage Milestone Escrow Tracker**: Visual progression for Deposit, Production, Inspection, and Settlement.
4. **Interactive Factoring Calculator**: Real-time Stroop return and APY slider calculations.
5. **NFC / QR Garment Verification**: Deterministic SVG QR codes and SHA-256 physical twin checking.
6. **Proof-of-Reserve Solvency Auditor**: Live on-chain reserve ratio validator.
